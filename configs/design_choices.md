# Per-stage design choices

This is the measured design record for G07's A2 knowledge-base work. It records
what has been observed and what is selected for the next implementation slice;
it does not turn an experiment, an external service result, or a placeholder
into a project score. At the time of this commit the Pierce loader is the only
implemented runtime stage in the starter. Stages marked pending are deliberately
not represented as complete.

| 0 Frame | Build a searchable, cited knowledge base from a scanned historical medical reference. The explainability target is 100% page citations, each human-verifiable in under 30 seconds. | R. V. ## Evidence boundary

- The development directory contains useful experiments, but its detector outputs,
  DocAI output, Chandra notebooks, model weights, virtual environments, generated
  crops, and credentials are not starter artifacts and are not committed here.
- Detector agreement is a prioritisation signal, not ground-truth accuracy.
- The paid Document OCR result is an external comparison, not a reproducible
  runtime dependency.
- The A2 form, held-out labels, `kb_demo.ipynb`, and the end-to-end index evidence
  still need to be completed before an `a2-submit` tag is honest.
