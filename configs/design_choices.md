# Per-stage design choices

This is the measured design record for G07's A2 knowledge-base work. It records
what has been observed and what is selected for the next implementation slice;
it does not turn an experiment, an external service result, or a placeholder
into a project score. The current branch now contains conservative baseline
implementations for ingest, identity preprocessing, projection layout, Tesseract
OCR, chunking, embedding, and FAISS persistence. A full-corpus run, hand-labelled
OCR score, and retrieval evidence are still pending, so code presence is not
represented as completed evidence.

## Evidence boundary

- The development directory contains useful experiments, but its detector outputs,
  DocAI output, Chandra notebooks, model weights, virtual environments, generated
  crops, and credentials are not starter artifacts and are not committed here.
- Detector agreement is a prioritisation signal, not ground-truth accuracy.
- The paid Document OCR result is a precomputed reference/pre-annotation source, not
  ground truth and never a query-time API dependency.
- The A2 form, held-out labels, real notebook outputs, and the end-to-end index
  evidence still need to be completed before an `a2-submit` tag is honest.
